# Kalkberg

This project is meant as a showcase for Datawijs. It shows how we handle data projects.

Please note that this data is synthetic. Kalkberg, its brands, creators, affiliate partners and customers are completely fictional. The exports are build to look and behave like the real thing, including the kind of problems you could encounter in real data. There is deliberately no list of those problems: finding them is part of the work.

## What you will find in this repo

```code
README.md                           --> Explains how to use this project
context.md                          --> Provides information about the fictional company and its requests
generator/                          --> Code to generate the data used for this project
docs/                               --> Step-by-step guide on what we did and why
```
